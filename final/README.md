# Integrated deliverable

This directory is reserved for the integrated public deliverable. Implementation and results are planned.

## Component flow
A_food_isolation -> B_nutrition_estimation -> C_daily_tracking -> D_meal_planning

The photo-estimation path uses public meal data. Gordon menu nutrition is used for recommendations, not as labels for arbitrary meal photos.

## Delivery checklist
- Provide setup/run instructions and pinned dependencies for the integrated demo.
- Reference shared implementations in ../src/ rather than duplicate component code.
- Link frozen split manifests, model/planner configurations, run records and small evaluation summaries.
- Record the commit or release used for the report and slides.
- All members share integration, simple UI, documentation and reproduction checks.

Keep the Canvas proposal PDF, member identity mapping, personal profiles/logs, raw datasets and large model checkpoints outside this public repository.
